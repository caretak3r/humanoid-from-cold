# Humanoid from Cold

Learning notes for building a humanoid **from cold start**: freeze frames and units, instrument one joint end-to-end, then chain contact, balance, stepping, shared autonomy, runtime safety, teleop+policy logging / replay / dataset hygiene, offline eval / shadow / canary under supervisor + logging gates, HIL regression farm under supervisor + logging + canary gates, fleet multi-robot shared-autonomy logging / ticket-log sync / online continual learning under the same gates, fleet canary orchestration / multi-site sim-to-real ranking under supervisor + logging + canary + HIL + fleet gates, and fleet incident response / coordinated rollback / multi-robot kill coordination under supervisor + logging + canary + HIL + fleet + fleet-canary gates. Physical build and digital twin share the same interfaces.

## Principle

Never put a neural net inside a microsecond loop until you have measured jitter.
