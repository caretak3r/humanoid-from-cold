## Runtime safety supervisor (Day 17) + logging / replay / hygiene (Day 18) + offline / shadow / canary (Day 19) + HIL regression farm (Day 20)

Supervisor sits above soft teleop / policy / arbiter. Logging tags soft vs measured vs power vs stage without promoting scores to MEASURED. Replay is soft-only. Hygiene quarantines dishonest episodes and keeps late-kill / demote / ESTOP as negatives. Offline eval / shadow / canary score and admit under the same gates — still soft; MEASURE and Day 05 still bind. HIL farm schedules twin+bench suites that re-score / re-run / dry-run those paths; RegressionGate fails closed on canary admit when races or hygiene regress — still soft; never a farm plant.
